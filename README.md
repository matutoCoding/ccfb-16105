# 掐丝珐琅图稿工坊

面向掐丝珐琅工坊的网页版图稿设计与烧制效果预览系统。TypeScript + WebGL2，图稿与釉料数据全部本地 IndexedDB 存储，不依赖后端。

## 启动

```bash
pnpm install
pnpm dev        # 开发
pnpm test       # 单元测试（含封闭格检测与千丝性能基线）
pnpm build      # 类型检查 + 生产构建
```

## 六大页面

| 路由 | 页面 | 职责 |
| --- | --- | --- |
| `/orders` | 订单 | 盘/瓶/摆件建档，胎面直径、曲率、客户原图 |
| `/wire-design/:id` | 丝工图 | 垫图描丝、二次/三次贝塞尔、封闭格检测、丝料清单、1:1 SVG 导出 |
| `/glazes` | 釉料库 | 色号建档，透明/不透明分开，透明釉记折射率 |
| `/firing/:id` | 点蓝烧制预览 | GPU 距离场、弯月面、砂眼、烧制遍数 |
| `/finish/:id` | 磨光镀金 | 找平、镀金反光、透明釉下地纹 |
| `/work-order/:id` | 出工单 | 按格编号列色号与填釉遍数，可打印 |

## 核心架构

```
src/core/
  geometry/
    bezier.ts        de Casteljau 递归细分，弦差容差 0.05mm
    intersect.ts     线段求交 + 整数键空间哈希
    planar_graph.ts  半边结构面枚举，自由端缺口零漏报
    wire_bom.ts      丝长/弯折次数/最小弯曲半径
    unfold.ts        瓶身圆柱展开与曲率弧长修正
  render/
    shaders.ts       手写 GLSL：距离场片元 + 烧制合成片元
    distance_field_renderer.ts
                     线段打包 RGBA32F 纹理，R32F 离屏距离场
  firing/random.ts   mulberry32 种子随机，砂眼可复现
  export/svg_exporter.ts
                     毫米物理尺寸 SVG，打印 100% 即 1:1
```

## 三条硬指标的实现方式

1. **封闭格零漏口**：贝塞尔细分 → 0.1mm 容差焊接 → 线段求交切分 → 半边平面遍历枚举全部面；度数为 1 的自由丝端一律按缺口标红，T 型焊等合法相交不误报。单测覆盖封闭框、缺口框、隔丝、T 型焊、近邻间隙。
2. **1:1 打印 ±0.2mm**：SVG `width/height/viewBox` 全部毫米单位，贝塞尔以原生 Q/C 命令输出而非折线，细分容差 0.05mm 为打印精度留四倍余量。
3. **千丝 50ms 刷新**：空间哈希把候选线段对从 O(n²) 降到近线性；点索引与网格均用整数哈希键避免字符串分配；面遍历预计算 next 边、遍历中累计面积。1000 根三次贝塞尔（14000 细分段）实测约 48ms。

## 单位与精度约定

- 全系统几何单位毫米，角度内部弧度、界面度数
- 焊接容差 `SNAP_TOLERANCE = 0.1mm`，细分弦差 `FLATNESS_TOLERANCE = 0.05mm`
- 距离场纹理单批上限 4096 线段，超出需分批渲染（当前上限内运行）

## 已知边界

- 丝编辑目前支持落点成丝与属性修改，控制点拖拽微调待补
- 瓶身展开按圆柱模型，异形摆件胎的自由曲面展开待扩展
- 距离场单批线段上限 4096，超大规模图稿需要分块纹理调度
